# Community support

Start with [installation](docs/installation.md), [configuration](docs/configuration.md) and [troubleshooting](docs/troubleshooting.md). When Discussions opens, use **Support** for setup, **Q&A** for general questions, **Ideas** for proposals, **Development** for design work and **Announcements** for maintainer news. These are suggested categories for repository setup.

Use the bug form for a reproducible defect and the feature form for a proposed change. Include version, environment and a fictional example. For accessibility or localization, describe the interaction and expected result. Community support has no guaranteed response time. [Security disclosure](SECURITY.md)
