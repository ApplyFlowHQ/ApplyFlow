# Roadmap

These proposals guide issue selection. Scope and scheduling depend on contributor capacity and verification.

| Horizon | Objectives |
| --- | --- |
| Short term | Complete release and rights review, test fresh installs across platforms, expand fictional mailbox and browser coverage, document uncertain handoff recovery. |
| Medium term | Improve provider failure handling, measure discovery precision, audit keyboard and mobile flows, test migration and restore paths, improve translation coverage. |
| Long term | Evaluate new discovery adapters with permission, broaden languages, benchmark multi-user workers and improve large-dataset tracking. |

Propose measurable improvements through the feature request form. Include an example of how a candidate or operator would benefit.
