# Finding a contribution

| Area | First contribution |
| --- | --- |
| Frontend, design, mobile | Test keyboard navigation and focus in the draft review flow at narrow widths. |
| Localization | Compare the English and Arabic presentation of statuses, dates and right-to-left layouts. |
| Discovery and integrations | Add a synthetic provider response and verify source and recipient evidence. |
| Automation and backend | Exercise retries, cancellation and duplicate prevention using a fake transport. |
| Database and performance | Profile a generated dataset or test a migration against disposable data. |
| Documentation and testing | Reproduce the install guide on a fresh checkout and improve a specific step. |
| Security | Review ownership, upload handling or credential storage and report issues privately. |

Use labels for purpose (`bug`, `enhancement`, `documentation`, `testing`, `accessibility`) and area (`frontend`, `backend`, `automation`, `integration`). Maintainers can label non-sensitive hardening tasks `security`. Reserve `good first issue` for scoped work with a clear verification step and `help wanted` for work ready to share.
